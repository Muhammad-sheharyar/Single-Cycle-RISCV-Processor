# Single-Cycle-RISCV-Processor
32-bit Single-Cycle RISC-V Processor designed in SystemVerilog.
## Overview
This project implements a 32-bit Single-Cycle RISC-V Processor in SystemVerilog.

## Features
- RISC-V RV32I Instructions
- ALU Operations
- Register File
- Immediate Generator
- Control Unit
- Data Memory
- Instruction Memory
- Branch Support
